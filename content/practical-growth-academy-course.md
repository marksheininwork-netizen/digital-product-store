# Practical Growth Academy — Course Blueprint (Draft)

**Companion to:** The Practical Growth Playbook  
**Audience:** Beginners, freelancers and small-business operators  
**Outcome:** Create and validate one specific offer, build a truthful landing page, produce a content plan, and measure a small launch.  
**Format:** 8 modules / 24 lessons / exercises and completion checks. No live coaching or video lessons are represented as completed.

| Module | Lessons | Practical submission |
| --- | --- | --- |
| 1. Customer research | Define the audience; conduct interviews; identify expensive problems | Customer evidence log |
| 2. Offer design | Define deliverables; write value proposition; set clear terms | One-page offer brief |
| 3. Ethical sales | Ask discovery questions; explain fit; handle objections honestly | Sales conversation script |
| 4. Pricing | Calculate margin; compare alternatives; test price hypotheses | Pricing worksheet |
| 5. Marketing pages | Write a headline; structure a page; improve accessibility | Landing-page draft |
| 6. Social media | Build content pillars; write short videos; repurpose across channels | 14-day content calendar |
| 7. Email and SEO | Design opt-in lessons; match search intent; audit discoverability | Seven-email outline and keyword map |
| 8. Launch and analytics | Test fulfillment; read funnel metrics; iterate responsibly | 30-day launch plan and scorecard |

## Assessment rubric
- **Specificity:** identifies one audience and one job.
- **Evidence:** distinguishes interviews, observations and assumptions.
- **Clarity:** a new visitor understands deliverables and limitations.
- **Execution:** files and workflows actually work.
- **Integrity:** no fabricated testimonials, false urgency or unsupported income promises.
- **Measurement:** defines a primary metric and records a baseline.

## Lesson template
Each lesson should contain: goal, 5–10 minute explanation, worked example, action task, worksheet, self-check question, and optional extension.

## Sample lesson — Write a useful hook
**Goal:** Draft a clear, truthful first sentence for a short-form video.
1. Name a customer and a problem they recognize.
2. Promise one useful insight, not a miraculous outcome.
3. Demonstrate the insight within the video.
4. End with one relevant action.

**Worked example:** “Three ways freelancers can avoid losing track of client follow-ups.” Show a single tracker with lead, next action and due date.

**Action:** Write five hooks for your product. Read them aloud, remove vague superlatives, and test which one a potential customer understands fastest.

**Self-check:** Does the video actually deliver what the first sentence promises?
